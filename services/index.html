What I build

Three specialisations, all of them taken end-to-end from architecture through deployment:

1. Finance dashboards (React + Node + PostgreSQL)

Custom dashboards for finance teams that replace spreadsheet rituals. Past builds cover P&L by entity, AR aging with cohort tracking, bank-to-ledger reconciliation, and expense automation with approval workflows. Every dashboard includes a freshness badge, CSV export, and an audit log because finance teams will not adopt a tool they cannot trace. See the finance dashboard case study →

2. Amazon advertising analytics platforms (Next.js + Puppeteer + PostgreSQL)

If the Amazon Advertising API does not expose what you need — typically keyword-level rank history and weekly comparison — a Puppeteer Stealth scraper against Seller Central is the production answer. End-to-end product builds with proper auth (JWT in HTTP-only cookies, not localStorage), state management (Redux Toolkit or RTK Query), and deployment. Recent example: NeoMail, a full-stack email client with MongoDB TTL auto-expiry. See the NeoMail case study →

How I work

The first call is 30 minutes, free, and is about scope rather than selling. After that:

  1. Discovery — one week. I read the existing codebase or talk to your team's spreadsheet owners. Output: a one-page brief covering scope, constraints, and what counts as done.
  2. Build — weekly demo, async written status update every Friday. I open a PR or push to a staging deployment by the second week so you can interact with what's being built instead of waiting on it.
  3. Handover — written architecture doc, runbook for deployment and common operational tasks, and a two-week support window for questions after the project closes.

Pricing is fixed-price for well-scoped builds (preferred for first engagements) and hourly retainer for ongoing collaboration. Indicative ranges live in the FAQ below.

Frequently asked questions

How much does it cost to hire a freelance React developer in India?

Rates vary by scope and experience. A senior freelance React developer in India typically charges between US $25 and US $75 per hour. For fixed-price dashboard builds, a production-ready MVP with auth, 3–5 views, and a small backend usually lands between US $3,000 and US $8,000 depending on data complexity and integrations.

How long does a typical finance dashboard project take?

A focused MVP (3–5 views, one data source, basic auth and CSV export) takes 3–5 weeks of build after a one-week discovery and scoping phase. Larger multi-entity platforms with audit logging, reconciliation flows, and reporting exports typically run 8–12 weeks.

What's the difference between MERN and Next.js for a SaaS dashboard?

MERN (Mongo + Express + React + Node) gives maximum control over the API surface and is the right pick when you have heavy backend logic or need MongoDB specifically. Next.js collapses the API and UI into one codebase with server-rendering, ISR and edge functions — it ships faster for dashboards that are mostly read-heavy with clear SSR/SSG wins. For finance and analytics dashboards specifically, Next.js with PostgreSQL is my default.

Can you scrape Amazon Seller Central for ad analytics?

Yes. I've built a production Amazon advertising analytics platform using Puppeteer Stealth that tracks ACOS, ROAS, CPC and keyword rank history across 18 ASINs and 3,500+ keywords. The scraper runs weekly via cron, parses Seller Central reports, and writes to PostgreSQL with a denormalised rank-history schema. Full architecture writeup →

Do you do fixed-price or hourly engagements?

Both. Fixed-price works well for clearly-scoped builds with a defined deliverable. Hourly works better for ongoing collaboration with shifting priorities. New clients usually start with a fixed-price first project, then move to hourly retainer if the working relationship is right.

Can a freelance developer integrate with our existing Node.js codebase?

Yes. Most of my work plugs into an existing API or database. Standard onboarding is a short walkthrough call, repo access, and a single small ticket as a calibration before larger features.

Is remote work outside India okay?

Yes. Working hours overlap with US Eastern (until ~1am IST), UK (until ~3am IST is the latest I'll commit to), and the entire EU + Asia-Pacific window. Async-first by default with a single weekly synchronous call.
